# Backlog

사용자가 원하는 것을 한 줄씩 적는다. 어디서 불편했는지(브리프, 버튼, 상태판, Claude Code 대화)를 붙인다. `plan-and-build`가 항목을 가져가 ADR과 phase가 되면 여기서 지운다.

기획 10장의 미정 사항(PITR 플랜, 식단 규칙 제약, 2차 자유 문장 입력의 모델)은 여기 다시 적지 않는다.

- [ ] 상비 재료: 땅콩버터, 계란, 밀가루처럼 큐브로 만들지 않고 늘 집에 있는 재료는 재고를 세지 않는다. 자동 차감, 부족 예측, 보류된 차감, 임계일 계산에서 빼고 재고 표에는 "상비"로 보인다. 재료 마스터의 속성이라 도메인 unfreeze가 필요하다. (Claude Code 대화: 계란이 재고 0이라 차감이 보류되고 부족 예측에 계속 올라옴)
- [ ] 임계일 섹션 제거: 상태판과 브리프의 임계일 목록을 없애고 재고 표에 임계일 열을 넣는다. 배치가 여럿이면 가장 이른 임계일을 보인다. 폐기 버튼은 브리프 메시지에 남긴다. (상태판: 재고 표와 임계일 목록을 따로 읽어야 함)
- [ ] 임계일 임박 강조: 임계일 3일 전부터 재고 표의 그 행을 굵게 하고 재료명 앞에 기호를 붙인다. 캔버스 마크다운은 셀 색이 없어서 ADR 0008이 정한 기호 방식을 따른다. 기획 4.5절의 "전일, 당일" 알람 기준을 "3일 전"으로 고친다. (상태판: 임계일이 가까운 행이 눈에 띄지 않음)
- [ ] 끼니 중량 상한: 이유식 시기(초기, 중기)마다 한 끼의 큐브 중량 합 상한이 있다. 초기 80g, 중기 120g. 한 끼 중량은 베이스 메뉴 큐브와 토핑 큐브의 1회분 중량 합이다. 시기는 시작일이 아기마다 달라 날짜로 계산하지 않고 식단 규칙에 현재 시기를 저장하며, 부모가 바꾼다. 지금은 초기다. 상한을 넘으면 다른 식단 규칙처럼 경고만 하고 식단을 고치지 않는다. 밀가루는 알러지 확인용으로 소량만 더하므로 1회분 중량을 0g으로 둔다. 지금은 1회분 중량이 1 이상이어야 해서(`INVALID_WEIGHT`, `ingredient_serving_weight_gram_check`) 0을 허용하는 변경이 함께 필요하다. (Claude Code 대화: 10/4 식단이 105g으로 초기 상한을 넘는데 서버가 모른다)
